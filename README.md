# DriveIstan

DriveIstan is a full-stack car rental platform for Pakistan, with customer booking flows, fleet management, verification, payments, and an admin dashboard.

## Planned stack

- Next.js + TypeScript
- Tailwind CSS
- Framer Motion
- PostgreSQL + Prisma
- Auth.js
- Leaflet maps

## Design source

The UI follows the DriveIstan design specification: dark-first surfaces, Electric Cyan primary actions, Luxury Gold accents, responsive desktop/mobile layouts, animated fleet cards, booking search, vehicle detail views, location hub, and admin command center.
